# 고객센터 주간 VOC 보고서

## 주간 운영 요약

이번 주 고객센터는 결제 문의가 가장 집중되었고 로그인과 배송 문의가 뒤를 이었다. 전반적인 문의 대응은 진행되었으나 SLA 초과와 미해결 건이 남아 있으며, 특히 높은 우선순위의 모바일 결제 오류와 배송 관련 문제가 고객 영향도가 큰 위험 요인으로 확인되었다. 배송 영역에서는 배송 위치 조회와 배송지 변경 반영 과정의 운영 공백이 함께 나타나 신속한 원인 점검과 후속 관리가 필요하다.

## 주요 VOC

### 미해결 사례

- `T004` 결제 · high: 모바일 결제 단계에서 반복 오류
- `T007` 배송 · high: 출고 완료 후 배송 위치 확인 불가
- `T011` 배송 · medium: 배송지 변경 요청이 주문에 반영되지 않음

### 분석 결과

- 모바일 결제 단계에서 오류가 반복되어 결제 완료를 방해하고 있으며, 재현 조건과 발생 원인에 대한 기술적 확인이 필요하다.
- 배송 완료 이후 위치 정보가 확인되지 않는 문제가 발생해 고객의 배송 불안과 추가 문의를 유발할 가능성이 있다.
- 배송지 변경 요청이 주문 정보에 정상 반영되지 않아 주문 변경 프로세스와 관련 시스템 간 연계 점검이 요구된다.

## 권장 조치

- 모바일 결제 오류의 재현 여부와 발생 환경을 우선 점검하고, 원인 파악 전까지 관련 문의를 집중 모니터링한다.
- 배송 위치 조회 불가 및 배송지 변경 미반영 건을 우선 처리하고, 주문·배송 시스템 간 정보 반영 상태를 확인한다.
- SLA 초과 건의 공통 원인을 검토하고, 미해결 고우선순위 이슈에 대한 담당자 지정과 진행 상황 공유를 강화한다.
